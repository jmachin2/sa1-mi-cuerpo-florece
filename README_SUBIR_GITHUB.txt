SUBIR AL REPOSITORIO sa1-mi-cuerpo-florece

1. DESCOMPRIME este ZIP en el ordenador.
2. En GitHub abre el repositorio jmachin2/sa1-mi-cuerpo-florece.
3. Pulsa Add file > Upload files.
4. Arrastra TODO el contenido de esta carpeta: index.html, assets, pdf, .nojekyll y este archivo si quieres.
5. Pulsa Commit changes.
6. Espera 1-2 minutos y recarga la web con Ctrl+F5.

IMPORTANTE: no subas el ZIP sin descomprimir. index.html debe quedar en la RAIZ del repositorio, y las carpetas assets y pdf deben conservar sus nombres.
